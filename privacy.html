What this site collects

The studio site is a static website. It has no accounts, no shopping cart, no newsletter, and no analytics or advertising scripts. We do not set cookies from this site, and we do not ask you to submit a form.

The site is hosted on GitHub Pages. When your browser requests a page, GitHub receives that request as the host and may keep ordinary server logs, such as IP address, time, and the page requested. Their practices are described in the GitHub Privacy Statement.
